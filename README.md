# Nombre del Proyecto

Esta es una aplicación web dedidaca a la comunidad lectora, donde los usuarios podrán buscar sus libros favoritos y encontrar la forma de adquirirlos. Además, a través del registro e inicion de sesión, podrán acceder a una biblioteca virtual donde podrán clasificar dichas lecturas, en función de si han sido leídas o no, continuidad de la lectura o historias deseadas para un futuro, proporcionando un registro de cada lectura del usuario.
